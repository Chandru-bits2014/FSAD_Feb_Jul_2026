Commands for Vite Project
After Opening a ProjectFolder(Empty)
1) Add "Vite" extension : "VSCode forVite"
2) npm create vite@latest
answer following prompts
--ProjectName :   enter     just  .  (dot) indicating current folder
--Select a Framework : React
-- Select a Variant : Javascript + SWC Or(just Javascript)

Then in the same cmd prompt type
3) npm i  [to install all dependencies]
4) to run app : cmd --> npm run dev

it will automatically run on browser then do the changes
NOTE : For all the above Prior to which nodejs should have been installed
